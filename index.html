Das Forum CORE-Forum- ist privat. Diese Seite ist öffentlich und enthält keine Forum-Inhalte. Sie liest und schreibt mit deinem eigenen GitHub-Token direkt bei GitHub. Das Token bleibt in diesem Browser und geht an keinen anderen Server.

  1. Fine-grained Token anlegen
  2. Repository access: Only select repositories → CORE-Forum-
  3. Permissions → Repository → Contents: Read and write. Sonst nichts.
  4. Ablaufdatum nach Wunsch, Token kopieren und hier einfügen.
